# Hentz Serviços de TI — portfolio

Portuguese-first, responsive portfolio for Rafael Hentz. The Next.js frontend introduces custom website creation, related software services, a clear delivery process, and verified personal and academic work. It uses the existing shadcn/ui component foundation. The existing backend remains in the repository.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

## Before launch

- Confirm the preferred public title and bio wording.
- Add 2–3 verified Hentz client projects, with permission, screenshots and case details.
- Confirm a preferred direct contact method/email.
- Verify current legal name and any disclosure details before publishing them.
- Verify project descriptions and links/demos against the repositories.
- Confirm authorization for any employer metrics before adding them.
